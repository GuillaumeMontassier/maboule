# 03 — Barre de recherche : repositionnement responsive

**What to build:** La barre de recherche de boulodrome se repositionne selon la taille d'écran : centrée en haut sur mobile, alignée à gauche sur desktop.

**Blocked by:** 01 — Mise en place de Tailwind CSS

**Status:** ready-for-agent

- [ ] En dessous de 768px de large, la barre de recherche est centrée horizontalement
- [ ] À 768px et au-delà, la barre de recherche est alignée à gauche (comportement actuel)
- [ ] Le composant est migré vers Tailwind (plus de dépendance aux règles CSS dédiées dans `App.css`)
- [ ] Aucune régression sur la recherche elle-même (soumission, affichage des résultats)
